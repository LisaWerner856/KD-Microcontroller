# KD-Microcontroller 

## Description
This is my recreation of the Simon Says game (electronic version). 
I programmed an Arduino uno to display light sequences and handle player input.
A list of components is included below. 

## Electronics
| Component | Ammount | Notes |
|-----------|---------|-------|
| Arduino uno | 1 | |
| 12mm push button | 4 | |
| LED | 4 | red, blue, yellow, green |
| Piezo buzzer | 1 | |
| Resistors | 4 | 220 Ohm |

## Future plans
In the future I plan on replacing the 12mm push buttons with 16mm push button (reset) with 6.3V led lighting.
Further I want to design and print 3D print a casing to contain the arduino board and the electronics, to make it feel more complete.
